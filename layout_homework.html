看代码找错

20 分

下面代码存在 3 处 bug，分别对应：①图片放大跑出卡片盖住旁边卡片；②文字展开移入有动画、移出无过渡；③卡片布局排版错乱。

原始代码（标注错误）

.box li{
    width: 300px;
}
.box img{
    width: 100%;
}
.box li:hover img{
    transform: scale(1.2);
    transition: all .6s;Bug②
}
.txt{
    position: absolute;Bug③
    bottom: 0;
    height: 40px;
    background: rgba(0,0,0,.6);
}
.box{
    display: flex;Bug①
}

三处 Bug 分析与修改

Bug①：图片放大跑出卡片，盖住旁边卡片

原因：li 没有设置 overflow: hidden，图片 scale(1.2) 放大后溢出 li 容器，覆盖相邻卡片。

修改：给 .box li 添加 overflow: hidden;，并添加 position: relative;（子绝父相）。

Bug②：文字展开只有移入有动画，移出无过渡

原因：transition 写在了 :hover 选择器里，鼠标移出时 transition 失效，元素瞬间回到原状。

修改：把 transition 移到默认选择器 .box li img 上，使移入移出都有过渡。

Bug③：卡片布局排版错乱

原因：.txt 使用了 position: absolute，但其父元素 li 没有设置 position: relative，导致文字条相对于更外层祖先定位，排版错乱。

修改：给 .box li 添加 position: relative;（子绝父相）。

修改后的完整代码

.box li{
    width: 300px;
    overflow: hidden;修复①
    position: relative;修复③
}
.box img{
    width: 100%;
    transition: all .6s;修复②
}
.box li:hover img{
    transform: scale(1.2);
}
.txt{
    position: absolute;
    bottom: 0;
    height: 40px;
    background: rgba(0,0,0,.6);
}
.box{
    display: flex;
}

03

手写原理简答

25 分

1. 父元素 position: relative，子元素 position: absolute 的盒子位置关系

下图用 CSS 绘制示意：父元素（蓝色）设为 relative，子元素（橙色）设为 absolute，子元素相对于父元素进行定位（bottom: 10px; right: 10px）。

父元素 position: relative
子元素 position: absolute

子元素 absolute 脱离文档流，以最近的已定位祖先（relative 的父元素）为参照定位

2. overflow: hidden 本节课两个作用

作用 1：裁切溢出内容 —— 给 li 设置 overflow: hidden，防止图片 scale 放大后溢出卡片容器，盖住相邻卡片。

作用 2：清除浮动 —— 当子元素浮动导致父元素高度塌陷时，给父元素设置 overflow: hidden 可以触发 BFC，从而清除浮动影响（本节课未用浮动，但这是 overflow:hidden 的经典作用）。

3. transform: scale(1.2) 会不会把盒子实际占位变大，挤压旁边卡片？

不会。transform 属于合成层属性，只改变元素的视觉渲染效果，不改变元素在文档流中的实际占位。图片 scale(1.2) 后，视觉上变大了，但它在布局中的位置和尺寸不变，因此不会挤压旁边的卡片。放大的部分会溢出容器，需要配合 overflow: hidden 来裁切。

4. transition 写在 hover 上和写在普通选择器上，鼠标移出动画有什么区别？

写在 hover 上：鼠标移入时有过渡动画，移出时没有过渡（瞬间跳回原状）。因为移出后元素不再匹配 hover 选择器，transition 属性失效。

写在普通选择器上：鼠标移入和移出都有过渡动画。因为 transition 始终生效，状态变化（无论进入还是离开 hover）都会触发过渡。

所以要实现"移入移出都有动画"，transition 必须写在默认（普通）选择器上。

5. 写代码遇到的 1 个 bug

现象：做卡片悬浮放大效果时，图片放大后会覆盖到旁边的卡片，看起来很混乱。

排查过程：先检查 transform: scale 是否写对，确认没问题后，发现是 li 容器没有限制溢出。图片放大后超出了 li 的范围。

修复方法：给 li 添加 overflow: hidden;，放大的图片部分被裁切在卡片内部，不再覆盖相邻卡片。同时给 li 加 position: relative 让内部文字条的 absolute 定位参照 li。

04

扩展挑战（选做）

15 分加分

实现左下角回到顶部按钮，纯 CSS 实现（不使用 JS）。效果见页面左下角的橙色圆形按钮 ↑

实现代码

.back-to-top{
    /* 固定在视口左下角 */
    position: fixed;
    left: 24px;
    bottom: 24px;
    /* z-index 保证浮于内容之上 */
    z-index: 999;
    width: 48px;
    height: 48px;
    border-radius: 50%;
    background: #e26d4f;
    color: #fff;
    text-align: center;
    line-height: 48px;
    text-decoration: none;
    font-weight: 700;
    /* 初始半透明 */
    opacity: .5;
    /* 移入移出都有过渡 */
    transition: opacity .3s ease, transform .3s ease;
}
.back-to-top:hover{
    /* hover 完全不透明 */
    opacity: 1;
    /* 轻微放大 */
    transform: scale(1.15);
}

按钮使用 <a href="#top"> 锚点跳转回页面顶部，无需 JS。
